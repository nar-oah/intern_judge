# BSN 关卡最小原型

本分支只演示 **Bevy 0.20 的 BSN 场景组合**，并非完整路网系统。保留原有的玩家跳跃与 Avian 碰撞。

## 运行与操作

```sh
cargo run
cargo test
```

A / D 移动、空格跳跃；靠近目标按 E。当前建筑和切换点用彩色矩形表示，效果记录在运行程序的日志中：

- **绿色便利店**：按 E 获得 5 秒的 1.5 倍水平移动速度，演示中不扣钱。
- **橙色餐厅**：按 E 获得 10 单位演示现金；仅可领取一次，防止无限刷钱。还未接入工作日重置。
- **黄色切换点**：左右各一个，按 E 在日志提示触发，不会加载其他路段或法院。

如果多个交互对象距离足够近，只有距离玩家最近的一个会响应。按键判定使用 `just_pressed`，持续按住 E 不会反复触发。

## 从哪里读代码

1. `src/level/road.rs`：整个路段的布局。根实体保存 `RoadId(1)`，每一个 `--` 表示一个新实体。此处配置平台大小和各物体位置。
2. `src/level/platform.rs`：平台场景。用同一个 `size` 配置 Sprite 与 Avian Collider，未来可以只改场景渲染实现。
3. `src/level/building.rs`：两个不同建筑场景，各自定义外观和 `Interactable` 类型。
4. `src/level/transition.rs`：可重复使用的切换点场景，不带目标配置。
5. `src/level/interaction.rs`：所有物体共用一套 E 键距离检测，通过 `match` 处理不同交互效果。
6. `src/player.rs`：方便测试便利店效果，新增了少量 `SpeedBoost` 的消费和倒计时逻辑。

## 为什么平台可以自由设置尺寸

关卡只声明 `@platform(Vec2::new(width, height))`。现在 `platform()` 用纯色精灵与矩形碰撞体；将来可以把 Sprite 换成纹理平铺或九宫格切片，而保持关卡中已有的尺寸与碰撞体不变。碰撞体和图片的最终适配仍需要在美术确定后检查。
